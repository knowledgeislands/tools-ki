# Batches

This directory holds temporary batch inputs for repository work while `ki-work` is declared. The `ki-batch` skill is retired: new batches are work packages under `ki-work-package`, and a record left here is read as it stands until it is removed.

Keep active records. Remove an inactive record as soon as its useful outcomes or follow-up are dispositioned, and treat an unresolved record as overdue at seven days. This README remains as the capability boundary.
