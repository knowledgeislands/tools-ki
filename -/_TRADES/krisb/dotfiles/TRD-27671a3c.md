# TRD-27671a3c: Refresh managed KI completion source

## Context

The KI CLI now generates the current Bash and Zsh completion grammar, but a terminal restart can reload Chezmoi's older static _ki artifact from fpath. This left retired commands such as repo plan visible after the CLI had moved to repo roadmap.

## Submission

Update the Chezmoi-managed Zsh completion workflow so its persisted _ki artifact is regenerated from ki manage completion zsh at the appropriate managed refresh point. Document the one-shell development check: source <(./bin/ki manage completion zsh).

## Constraints

Chezmoi owns the user-environment configuration and acceptance decision. Keep the generated source static at shell completion time; do not invoke ki dynamically on every completion. Verify a fresh Zsh session offers repo roadmap and does not offer retired repo plan.
