## Goal

Prove one complete ChatGPT project move and one completed agent-session no-op before any source deletion can be enabled.

## Context

Kris approved this tools-ki-owned OPS009-SPLIT capture on 20 October 2026 at 23:16 BST. A complete-project result must account for the project and all required content, while a completed agent session that has already been acquired must support a verified unchanged retry without another acquisition write.

Authority and provenance: [OPS009-SPLIT source requests](https://github.com/knowledgeislands/ki-principal/blob/20b5fce0bb34c213b3bfcec9c7e437eef5e45e1e/+/_WORK/ki.tools-burndown/messages.md).

## Boundary

This record captures the tools-ki proof requirement only. It excludes enabling or performing source deletion, provider mutation, source evaluation, receiver policy, and implementation of the companion importer, explicit-failure and retirement-design slices. Capture does not authorise a live acquisition, source move, provider call, implementation or publication.

## Discussion

### Complete-project evidence

The complete ChatGPT project move must establish project membership and preserve complete conversations, write-ups and required assets, with destination verification and explicit coverage. Here, move describes the verified acquisition outcome; it does not grant source deletion. A single conversation, partial export or digest is insufficient proof of a complete project.

### Completed-session no-op

The agent-session proof must use a completed session and demonstrate that an unchanged, already acquired source produces a verified no-op. Missing, changed or unreadable material must not be classified as unchanged. Later planning must specify reproducible evidence and the authorised source or fixtures without borrowing credentials or live-operation authority from this capture.

### Deletion prerequisite

Both proofs are required before any source deletion is enabled. Passing them does not replace the separate human-current-manifest, recoverable-copy-for-every-entry and unchanged-source gates, or itself authorise retirement. No adoption or proof execution occurs at capture.
