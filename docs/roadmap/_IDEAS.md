# Ideas

Ideas this repository may take up later. None is a work record: an idea here has no identifier, horizon or status, and it returns to the roadmap only when Kris brings it back. Each bullet says in plain language what the idea is for and links to its full text in `docs/ideas/`, kept as it was when it left the roadmap under the roadmap sweep of 27 October 2026.

- **Work status views contract** - Publish the five views of ki work status as JSON under a schema so the Observatory reads them from a contract; the text views serve the Observatory today, so a schema is premature. [Full text](../ideas/KI-TOOL-KI-CLI-149-work-status-views-contract.md) (was `KI-TOOL-KI-CLI-149`).
- **Readable ChatGPT project acquisition** - Acquire a whole readable ChatGPT project with complete conversations and provenance; the acquisition Project is finished. [Full text](../ideas/KI-TOOL-KI-CLI-168-readable-chatgpt-project-acquisition.md) (was `KI-TOOL-KI-CLI-168`).
- **Guarded source retirement design** - Design a guarded way to delete an acquired source only after every safety gate passes; nothing deletes sources today, so there is nothing to guard. [Full text](../ideas/KI-TOOL-KI-CLI-170-guarded-source-retirement-design.md) (was `KI-TOOL-KI-CLI-170`).
- **Complete acquisition move proof** - Prove one complete ChatGPT project move and one agent-session no-op before source deletion could be allowed; only needed for the retirement design, which is not wanted. [Full text](../ideas/KI-TOOL-KI-CLI-171-complete-acquisition-move-proof.md) (was `KI-TOOL-KI-CLI-171`).
- **KI release contract** - A documented release contract for ki with per-platform archives, checksums, signing and an installer; every machine runs ki from the linked checkout and releases are deprioritised, so there is nothing to contract for now. [Full text](../ideas/KI-TOOL-KI-CLI-125-ki-release-contract.md) (was `KI-TOOL-KI-CLI-125`).
- **EBU sources sync** - Let ki keep a repository's copy of the EBU 5G-EMERGE SharePoint documents in step with SharePoint; a Humans Not Robots need rather than a KI one. [Full text](../ideas/KI-TOOL-KI-CLI-139-ebu-sources-sync.md) (was `KI-TOOL-KI-CLI-139`).
- **Thread session bindings** - Bind a native Claude or Codex session to its logical thread so a session knows which thread it is and what role it plays; waits on harness thread work and a launch-style probe. [Full text](../ideas/KI-TOOL-KI-CLI-145-thread-session-bindings-role.md) (was `KI-TOOL-KI-CLI-145`).
- **Validator parity** - Make ki work and the harness roadmap checker read one shared field rule table with conformance cases, so the two cannot drift apart; the tools-burndown Project is on hold. [Full text](../ideas/KI-TOOL-KI-CLI-157-validator-parity.md) (was `KI-TOOL-KI-CLI-157`).
- **Explicit acquisition failure outcomes** - Make acquisition report unmapped projects, overlapping mappings, missing or changed sessions and failed reads as explicit outcomes, so nothing is silently dropped; worth keeping, deferred for now. [Full text](../ideas/KI-TOOL-KI-CLI-169-explicit-acquisition-failures.md) (was `KI-TOOL-KI-CLI-169`).
