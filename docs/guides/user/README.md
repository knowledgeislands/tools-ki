# tools-ki user guides

These guides explain bounded operating workflows exposed by the `ki` command. They are for people and agents using `ki` with registered repositories; contributor mechanics remain in the [developer guides](../developer/README.md).

- [Associate external Agora references](agora-references.md) — connect ordinary Git checkouts to an Agora working set without turning them into KI members.
- [Canonical batch records](batch-records.md) — prepare, bind, record, and close exact-set batch authority envelopes.
- [Acquire Granola meetings](granola-acquisition.md) — activate the adapter, import read-only meeting evidence, resume interrupted work, and govern reset or disposition.
- [Repository-local governance](repository-local-governance.md) — declare and run a repository-owned `ki-self` capability.
- [Standing knowledge intake](standing-knowledge-intake.md) — establish reciprocal knowledge grants and capture commit-pinned provenance.
- [Manage local VS Code projections](vscode-management.md) — reconcile chezmoi-owned workspace and trusted-folder source state.
