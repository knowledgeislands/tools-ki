# tools-ki developer guides

These guides are for contributing to and releasing `tools-ki` itself. If you are operating `ki` rather than changing it, read the [user guides](../user/README.md).

Work through them in the order a change travels.

- [Local development](local-development.md) explains how to run, build, and link a checkout while developing the CLI, including the `ki dev local` lifecycle for serving a harness from a local source.
- [Definition of done](definition-of-done.md) explains the delivery boundary, public-surface review, verification, and review handoff for a completed change.
- [Release tools-ki](releasing.md) explains release signing, GitHub protection, verified platform publication, and downstream distribution.
